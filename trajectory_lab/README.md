Навчальний пакет до ЛР1, заняття 3. Автор навчальних матеріалів: **Вернік М. О.**

Контрольований приклад із PhD-проєкту: навчити умовну модель Борна, перевірити її на нових синтетичних днях, згенерувати результати з навченого розподілу та побудувати рисунки Matplotlib.

## Запуск

У середовищі Python 3.11+ встановіть `requirements.txt`. Після цього:

```text
python run_lab.py --mode replay --out run_replay
python run_lab.py --mode train --out run_train
python check_lab.py
python analyze.py --out student_analysis.json
```

Для двох останніх команд спершу реалізуйте три функції в `tasks.py`. Викладацька перевірка: додайте `--solution`. `solutions.py` містить готові відповіді; вилучіть його зі студентського роздаткового архіву, якщо потрібна самостійна робота без підказок.

Кожен запуск потребує нового каталогу результатів. Replay перераховує збережені прогнози; train справді навчає шість моделей і порівнює їхні ймовірності з архівом. Контрольні метрики в `verified_run` отримані повторним навчанням, а не переписані вручну.

## Очікуваний результат

На 885 переходах із днів d10–d14: рівномірна модель NLL 2.0794; лише тип завдання 1.6204; Born Gray без CNOT 2.0078; Born Gray із CNOT 1.3408; класична softmax 0.7881. Менше краще. Born з CNOT навчається корисному розподілу, проте класична модель сильніша.

Дані генератора мають структуру та шум, але це не EEG людей. Протокол оцінює наступне спостереження за справжнім попереднім станом. Він не перевіряє вільну генерацію цілого дня, користь рекомендацій чи причинний ефект перерв.

## Рисунки

`figures.py` використовує Matplotlib і створює PNG та SVG: порівняння NLL, показники за днями, теплову карту прогнозів першого тестового дня і частоти вибірки першого тестового контексту. Числа походять із прогнозів; результативний день не обирається вручну. Випадковість використана лише у визначеному генераторі даних, навчальній ініціалізації й категоріальній вибірці.

Документація: [Matplotlib](https://matplotlib.org/stable/users/explain/quick_start.html), [scikit-learn log loss](https://scikit-learn.org/stable/modules/generated/sklearn.metrics.log_loss.html).

## Походження

Чотири `trajectory_*.py` – незмінені копії модулів PhD-проєкту; їхні контрольні суми збігаються з `evidence/config.json`. Історичні дослідницькі міркування у коментарях цих модулів не є додатковими перевіреними результатами лабораторної. `provenance.json` фіксує походження архіву й модулів. Для навчання не завантажуються pickle-файли чи зовнішні дані.

`born_state.npz` зберігає числові параметри та нормований тестовий контекст для огляду. Це не повний автономний сервіс прогнозування сирих вхідних даних; для такого використання потрібні також перетворення контексту з навченого об’єкта моделі. `analyze.py` демонструє інтерфейс на архівних прогнозах.
