# Модуль цифрового двійника на основі моделі Борна та NSGA-II

Тема PhD: **«Методи та програмні засоби побудови цифрових двійників когнітивного стану людини на основі квантових моделей та метаевристик»**.

Центральний результат практичної роботи – програмний модуль, який розділяє спостереження і прогноз, отримує розподіл наступного стану від моделі Борна, обирає конфігурацію за валідаційною якістю та бюджетом, а за недоступності квантового симулятора використовує класичний прогноз. Це навчальна реалізація частини архітектури цифрового двійника, а не доказ користі планування для людини.

## Запуск

Папки twin_lab, trajectory_lab і data_lab мають залишатися поряд. Перевірене середовище: Python 3.13.5, NumPy 2.1.3, SciPy 1.15.3, scikit-learn 1.6.1, Matplotlib 3.10.0.

```text
cd twin_lab
python -m pip install -r ../data_lab/requirements.txt
python run_twin.py --out my_run
python check_twin.py --run my_run
```

Перша команда run_twin.py працює одразу й заново навчає моделі. Для перевірки студент має заповнити tasks.py. Еталон викладача: `python check_twin.py --solution --run my_run`. За потреби незалежно відтворіть реальну спостережувальну частину: `python ../data_lab/run_real.py --out my_eeg_run`.

## Дані та межі інтеграції

Реальне спостереження береться з data_lab/reference_run/eeg_predictions.csv: це оцінка складної умови MATB-II для відкладеного учасника. Вона не є наступним рівнем стану.

Прогноз навчається на окремому синтетичному стенді проєкту: 15 днів із відомим контекстом і наступним значенням, 8 навчальних / 2 валідаційних / 5 тестових; відповідно 1416 / 354 / 885 переходів. Межі восьми рівнів визначаються тільки на навчальній частині. Контекст належить моменту прогнозу. Розриви запису не перетворюються на переходи відновлення.

Ці домени не з’єднано як одну часову траєкторію. Адаптер відмовляється прикріпити синтетичний прогноз до реального EEG. Для реального домену повертається спостереження з forecast=null і причиною відсутності відповідної моделі. Для синтетичного домену працюють Born та classical_fallback. Обидва навчальні прогнози мають planning_allowed=false. Реальний модуль прогнозу можна підставити через той самий інтерфейс після окремої перевірки на відповідних часових даних.

## Квантова модель

Для восьми рівнів використано три кубіти. Схема застосовує по три Ry на шар; якщо CNOT увімкнено, додається кільце з трьох CNOT на шар. Кути залежать від контексту. Квадрати амплітуд утворюють вісім імовірностей наступного рівня; код Грея визначає відповідність базисних результатів рівням. Параметри навчаються Adam із parameter-shift градієнтами, 8 епох, seed=20261005.

Окремо навчаються шість схем: L=1,2,3 × CNOT=0,1. Це точне класичне моделювання квантової схеми засобами NumPy. Кожна схема оцінюється з S=64,128,256,512,1024 змодельованих вимірювань. Для counts n_k застосовано фіксоване згладжування p_k=(n_k+0,5)/(S+4), щоб нульові лічильники не давали нескінченного NLL. Для валідації усереднено NLL восьми повторів вимірювань із seeds 20261007–20261014; вони не є вісьмома незалежними навчаннями мережі.

## Метаевристичний пошук

Цілі: f1=валідаційний NLL та f2=логічні gate-shots G=S×3L×(1+CNOT). Це умовна ресурсна міра кількості логічних гейтів у повторних вимірюваннях. Вона не вимірює час пристрою, транспільовану глибину, енергоспоживання чи повну вартість навчання.

NSGA-II: 3 гени у [0;1] кодують L, CNOT і індекс S; популяція 12, 10 поколінь, seed=20261007, усього 120 пропозицій. SBX, поліноміальна мутація, недоміноване сортування та crowding реалізовані у проєктному h1_optimizers.py. Усі цілі обчислюються за навченими моделями та валідаційними мітками, без випадково намальованих точок.

Після пошуку обирається найменший dev_nll серед відвіданих конфігурацій із G≤4608; при рівності – менший G. Тестові мітки до цього вибору не використовуються. Контроль повним перебором усіх 30 конфігурацій перевіряє якість вибору. Цей перебір і попередня підготовка всіх оцінок входять до навчального скрипта; не можна стверджувати економію загального часу на підставі того, що NSGA-II відвідав лише 21 конфігурацію.

## Результати

Зафіксовано L=3, CNOT=1, S=256, G=4608. Валідаційний NLL=1,282438. Обраний варіант збігається з найкращим у повному переборі за цим бюджетом; відхилення за dev NLL дорівнює нулю. Це один зафіксований навчальний запуск, не статистичний доказ переваги NSGA-II.

На 885 окремих тестових переходах: uniform NLL=2,079442; лише діяльність=1,620371; обрана Born із точними ймовірностями=1,340814; Born із 256 shots та згладжуванням=1,347543; класична softmax=0,788074. Отже, студент отримує навчену квантову модель кращу за прості базові моделі, обмежений ресурсами вибір та працездатний резервний режим. Переваги над класичною softmax немає; користь реального планування не перевірялася.

Рисунки Matplotlib: architecture (схема зв’язків, не дані експерименту), learning (фактичні навчальні втрати у точках 0, 1 та 8 епох; значення у training_history звіту), pareto (30 обчислених конфігурацій), twin_result (відкладений тест). Усі PNG та SVG включено до reference_run. Повний звіт містить параметри, локальний час навчання, усі покоління пошуку та три приклади відповіді адаптера.
